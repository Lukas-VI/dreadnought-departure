# Dreadnought Departure — 开发路线图

> 六角格海战兵棋推演 + 二游叙事 · Godot 4 C# · 2026-06

---

## 🔴 P0 — 核心玩法闭环（必须完成才能\"玩起来\"）

### 回合系统完善
- [ ]  **胜利/失败判定**：TurnManager 检测任一方全灭 → 弹出结果面板
- [ ]  **岛屿阻挡移动**：移动前查 terrainData，island 格子拒绝移动

### 海战核心机制
- [ ]  **航向系统**：ShipComponent 增加 Direction（六角格 6 个方向），船有朝向
- [ ]  **惯性移动**：每回合船可沿着当前航向\"冲\"指定格数，不可瞬移任意方向
- [ ]  **转弯限制**：每格移动最多偏转 TurnRate 度，不能原地掉头
- [ ]  **速度档位**：全速/巡航/停船，影响可移动格数和被发现概率
- [ ]  **移动可视化**：高亮当前航向可到达的格子（不是圆形，是锥形方向图）
- [ ]  **堆叠修整**：同一格多艘船不再完全重叠，微偏移 + 顺时针排布

### 战斗系统
- [ ]  **射界限制**：攻击受航向影响，只能打前方扇形范围内的目标
- [ ]  **距离衰减**：越远伤害越低，引入有效射程/最大射程
- [ ]  **弹药系统**：每场战斗有限弹药，用完只能撞角或撤退

### 轮盘菜单
- [ ]  **替换 emoji 为图标**：用 Sprite2D/TextureRect 替代 emoji 文字
- [ ]  **动画入场**：Tween 缩放入场 + 旋转展开
- [ ]  **方向型选项**：根据船的朝向排列按钮（前方=攻击，左右=转向）
- [ ]  **技能按钮**：从 ShipData.SkillIds 动态生成，每艘船不同

## 🟡 P1 — 内容与数据（让游戏\"有得玩\"）

### UnitSpawner / 关卡数据
- [ ]  **FleetComposition 资源**：关卡配表，存 ShipIds 数组 + 初始位置
- [ ]  **多关卡支持**：LevelDataManager 接受关卡 ID，加载不同 map_XX.json
- [ ]  **敌方编队多样化**：多艘不同类型船组成敌方舰队

### ShipData 扩展
- [ ]  **ShipAbility 技能系统**：每个技能 = Resource，含 CD/效果/动画
- [ ]  **被动属性**：装甲类型（对穿甲/高爆抗性）、雷达范围、隐蔽值
- [ ]  **升级/改造系统**：ShipData 支持等级，数值随等级成长
- [ ]  **技能冷却**：每回合减 CD，0 可用

### 存档系统
- [ ]  **战斗存档**：Save/Load 当前棋盘状态（船位置、HP、行动记录）
- [ ]  **多存档槽**：Slot 1-3

## 🟢 P2 — 视觉与体验（让游戏\"好看好玩\"）

### 3D 视觉
- [ ]  **船模替换**：用 Blender 导出的 glTF 模型替换 BoxMesh 方块
- [ ]  **水面效果**：Shader 海面 + 船行尾迹
- [ ]  **攻击特效**：炮口闪光 Tween → 弹道线 → 爆炸粒子
- [ ]  **击沉动画**：Tween 下沉 + 气泡粒子 → QueueFree
- [ ]  **网格线/装饰**：六角格边框线、坐标标注
- [ ]  **岛屿模型**：用 glTF 替换 CylinderMesh

### UI 层
- [ ]  **BattleHUD 重构**：当前回合标识横幅（带 Tween 动画滑入滑出）
- [ ]  **船信息面板**：选中船时底部弹出半透明面板，显示 HP/航速/技能 CD
- [ ]  **小地图**：俯瞰视角缩略图，显示船/岛位置
- [ ]  **行动预览**：鼠标悬停格子显示命中率/伤害预估值
- [ ]  **战斗日志**：滚动文本记录所有战斗事件

### 摄像机
- [ ]  **自由旋转**：鼠标右键拖动绕 Y 轴旋转
- [ ]  **缩放**：滚轮拉近拉远
- [ ]  **聚焦动画**：Tween 移动到选中船上空
- [ ]  **演出镜头**：敌方行动时短暂切到敌方视角

## 🔵 P3 — 二游系统（让游戏\"能运营\"）

### 主界面
- [ ]  **TitleScreen 场景**：Logo + 开始游戏 / 编队 / 设置 / 退出
- [ ]  **舰队编成界面**：从拥有的船中挑选出战阵容
- [ ]  **商店/抽卡**：资源抽卡 → 获得新船

### 角色系统
- [ ]  **CharacterData 资源**：船长/指挥官，含立绘、台词、被动技能
- [ ]  **好感度/羁绊**：出战积累好感，解锁剧情
- [ ]  **配音/台词**：战斗事件触发语音（开火/受击/击沉/胜利）

### 剧情
- [ ]  **对话系统**：DialogBox + 立绘切换 + 打字机效果
- [ ]  **关卡间剧情**：战前/战后对话
- [ ]  **分支剧情**：根据战斗结果走向不同分支
