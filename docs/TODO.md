# Dreadnought Departure — 开发路线图

> 六角格海战兵棋推演 + 二游叙事 · Godot 4 C# · 2026-08-01

## 当前进度快照

核心链路已打通：主菜单 → 画布选择 → 地图编辑器 / 战役。

- 地图编辑器：v3 画布 JSON（Terrain / Generation / Special / Ships）的新建、打开、导入、删除、保存；新建画布支持 E/W 水平向与 N/S 竖直向两种六角朝向；铅笔 / 填充 / 橡皮 / 框选 / 网格线；右键生成点检查器可配置阵营、舰型、航向、初速，单格最多堆叠 3 艘。编辑器地块已改为程序化绘制（六边形边框 + 采样 3D 地块材质填充），NS 朝向由绘制逻辑自动旋转，不再使用 tileset PNG 或额外旋转贴图；旧 2D TileMap 提取兼容路径与 `map_editor.tscn` 已删除，战斗场景只从 JSON 加载地图。
- 战斗链路：LevelDataManager → MapGenerator / UnitSpawner 数据链路打通；8 阶段管线（速度调整 → 三段移动 → 视野 → 炮击 → 鱼雷 → 结算）；逐船操作队列 + 底部弹性菜单；CP 消耗；炮击选目标与 PendingDamage 结算；三个移动阶段各自推进时立即惯性移动 Tween；相机滚轮缩放 / 中键旋转 / 聚焦动画；白天地图自动跳过照明阶段。
- PvP 联机：邮箱注册/登录（测试免密）→ 长效 token 本地持久化与自动恢复 → 大厅开房/加入/离开 → 房主上传地图与 ShipData → 服务端权威阶段机（速度/三段移动/炮击/结算）→ 服务器授时倒计时 → 单纵阵/堆叠同步 → 胜负结算与房间生命周期。
- 服务端管理后台：`/admin` 可视化数据总览、账号/房间/战斗/会话管理、骰值与抽卡日志。
- 网游中心：个人资料/昵称、背包、抽卡、商店、邮件系统已打通基础链路。
- 对话与演绎：基础对话框/背景/脚本、全局与战斗内触发器、玩家操作/特殊格通联接口。
- 关卡胜负条件：声明式 `Victory` 配置支持到达、检查点、动作、击毁、存活与回合限制。
- 作战菜单：章节选择、关卡数轴、章节记忆、进入章节/完成关卡剧情事件。
- 编辑器新建画布可逐阶段配置每船限时与鱼雷开关，打开已有画布后还能修改地图昼夜、主动权归属、CP/指挥、视野、回合数、鱼雷模式；大型舰主炮/副炮按前/侧/后射界独立射击；雷达已改为炮击阶段可显式激活的技能。
- 舰船数据：ShipData 资源 + ShipCatalog 目录扫描，已有无畏舰 / 杂鱼等多类，包含 HP、航速、射程、口径、三段装甲、技能 ID 等字段。
- 输入修复：BattleInputDetector 点击已改为路由到 EventBus.HexClicked，并完成 headless 冒烟验证。

当前状态：P0 核心闭环已完成（进图 → 操作 → 结算 → PV/指挥值判定）；剩余夜战照明、烟幕/照明弹、通用技能、鱼雷实体玩法等细节转入打磨与后续优先级。

## 🔴 P0 — 核心玩法闭环（必须完成才能"玩起来"）

### 回合系统完善
- [x] **胜利/失败判定**：结算后检测任一方全灭 → BattleUI 弹出结果面板
- [x] **指挥值与 PV 评分**：舰船损伤按规则书 4.3 减少指挥值，双方 CP 独立补充并受当前指挥值上限约束；中破/大破/沉没按 PV 比例计分，回合上限到达后按分数判胜负
- [x] **岛屿阻挡移动**：阶段移动逐格检查 terrainData，island 格子拒绝进入；撞岛船直接沉没
- [x] **敌方 AI 接入阶段管线**：玩家队列清空后同阶段自动接续敌方行动；AI 负责变速、转向与射程内炮击
- [x] **鱼雷阶段开关**：关卡 JSON 可配置 `TorpedoPhaseEnabled`，默认关闭，未启用时跳过鱼雷阶段
- [x] **待命指令预览**：速度/转向/炮击先写入 pending，只有手动推进才提交；全部指定后拉高相机等待推进

### 海战核心机制
- [x] **航向系统**：ShipComponent 已有 Direction（6 向）、朝向旋转与 HUD 显示
- [x] **惯性移动**：A2 SpeedTable 按纸质速力表（0-8，速度 1 仅奇数回合第一段 +1）映射三阶段位移；各阶段推进时立即惯性移动
- [x] **单纵阵（部分）**：同速同向、首尾相邻编队检测与编队标记，同格堆叠视为同一列；头舰变速同步写入跟随舰并只扣 1 CP，转向按首舰完整历史轨迹逐格延迟（贪吃蛇），支持多个转向点与无移动阶段转向，手动选中可覆盖/离队
- [x] **单纵阵提示与列表分组**：操作卡片预测组成/切断单纵阵并高亮（第三行“组成/切断”），左右舰船列表按单纵阵分组显示“阵1/阵2/阵3……”
- [x] **转弯限制**：转向与移动分离，不消耗移动步数；每格最多偏转 60°，单机与 PvP 共用逐格路径生成器
- [x] **速度档位**：速度调整阶段可加速/减速，CP 限制 + 当前状态 MaxSpeed 限幅；损伤降速延迟到下一回合速度调整阶段
- [ ] **移动可视化（部分）**：已有攻击/机动高亮接口；已改为单格下一到达预览（转向/加减速后刷新），逐格路径约束仍未实现
- [x] **堆叠与局部侧向偏移**：初设支持每格最多 2 艘；移动可进入同阵营占位格（上限 2），敌舰/满堆叠仍阻挡；移动后按堆叠序号沿当前航向的局部侧向轴左右并排，Y 保持统一高度，沉没后自动重排
- [x] **冲撞检定（简易占位）**：移动受阻时 1D10≤2 触发冲撞并按简化 A3 表损伤；完整 A3 表与超堆叠检定后续再精确

### 战斗系统
- [x] **射界限制**：炮击按 Firepower.ForArc 校验航向扇面，且前/侧/后火力值参与伤害系数
- [x] **射界高亮材质**：正前/正后各 60° 用 `mat_attack_front`，左右各 120° 侧射用 `mat_attack_side`，整体顺时针偏转 60° 对齐
- [x] **距离衰减**：命中率/装甲分段/口径基础伤害已实现
- [ ] **视野与雷达（部分）**：基本视野 + 岛屿遮挡 + 雷达扩展与雷达技能已接入；烟幕/照明弹未做
- [x] **副炮与前后侧火力**：主炮/副炮分别按前/侧/后射界独立结算，大型舰一次射击同时打主炮与副炮
- [ ] **弹药系统（部分）**：主炮有限弹药已实现并在 HUD/菜单体现；鱼雷实体玩法（发射/移动/命中/装填）已后推，不再占 P0

### 操作菜单
- [ ] **操作菜单改造（部分）**：已用底部卡牌式 PhaseActionMenu 替代轮盘，按钮仍是文字
- [o] **动画入场**：PhaseActionMenu 使用 Back 缓动弹出，但是还可以更高级灵动
- [x] **方向型选项（已取消）**：原轮盘菜单曾计划按六个航向排布按钮；改用底部 PhaseActionMenu 后不再需要，保持线性按钮布局
- [ ] **技能按钮（部分）**：菜单已读取 SkillIds 生成按钮，但无技能效果逻辑
